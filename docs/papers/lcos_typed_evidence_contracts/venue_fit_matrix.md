# Venue Fit Matrix

| Venue or surface | Fit | Evidence required |
|---|---|---|
| Immediate repo publication | Strong | Current proof pair, evidence map, and tests are enough. |
| Short workshop note | Plausible | Tight framing, diagrams, and explicit non-claims. |
| Governance / responsible AI workshop | Plausible after more examples | More fixtures and small reviewer-facing evaluation. |
| AIES / FAccT | Later | Empirical layer showing how reviewers use HOLD and replay records. |
| Security venues | Later only | Threat model, tamper resistance, signing or external attestation. |
| Systems venues | Later only | Runtime measurements, baselines, failure modes, and broader artifact evaluation. |

## Immediate Recommendation

Publish this first as a repository proof note. Do not submit it as an archival
systems or security paper until the evidence layer is expanded.
