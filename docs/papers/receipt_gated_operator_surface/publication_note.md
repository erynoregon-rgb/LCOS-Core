# Publication Note

This paper is published here as a **public research draft** accompanying
LCOS-Core.

LCOS-Core is a bounded public repository. This package is a mirrored public
paper surface imported from the SKOS-Core paper workspace and published here
for inspection. It should be read as a research draft plus evidence bundle, not
as a claim that every cited source path is implemented inside LCOS-Core.

## This draft does not claim

- production deployment
- adversarial hardening against privileged modification
- disclosure of non-public SKOS implementation details
- cryptographically signed transparency infrastructure
- general AI-system safety

## Evidence boundary

The paper package should be read with:

- `evidence_map.md`
- `claim_ledger.yaml`
- `review_response_matrix.md`

Claims that are not backed by cited code, tests, schemas, or receipts are
treated as hypotheses rather than results.
